# End-to-End Testing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A one-command end-to-end check of the real pipeline, API and dashboard, plus a written test report from one full run.

**Architecture:** A pytest suite in `backend/e2e/`, kept out of plain `pytest` by `backend/pytest.ini`. It serves the real Flask app (wired to analyse 5 stored articles per run) and the production frontend build from threads inside the test session, drives the dashboard with Playwright's Chromium, checks the database with its own Supabase queries, and writes `results.md` per session. Real collection runs only with `--collect`.

**Tech Stack:** Python 3.13, pytest 8, pytest-playwright 0.10 (Playwright 1.63, Chromium), werkzeug 3.1, supabase-py 2.31, requests 2.32, Vite 5 build, React 18.

**Spec:** [`docs/superpowers/specs/2026-10-08-e2e-testing-design.md`](../specs/2026-10-08-e2e-testing-design.md)

## Global Constraints

- Run every command from `backend/` unless a step says otherwise.
- Plain `pytest` (no paths) must collect only `tests/` and `agents/topic/`.
- The e2e suite's test server always collects **stored articles only, 5 per run**: `build_default_registry(live=True, backlog=True, backlog_limit=5)`.
- Real collection uses `sources=["rss", "gnews"]` only. **Never NewsAPI.**
- Credentials come from `backend/.env`, or the file `E2E_ENV_FILE` names, loaded with override before the app or any agent is imported. Results record the database **host only**, never the key.
- Expected values come from the suite's own Supabase queries (`e2e/database.py`), never from the code under test.
- LLM output varies: assert that classification rows exist and when they were written, never their values.
- Limits: 300 s per pipeline run over stored articles, 600 s for the real collection run, 60 s for servers and the frontend build, 30 000 ms per page load or dashboard update.
- Results go to `backend/e2e/results/<YYYY-MM-DD_HHMMSS>/` (ignored by git).
- **Every `python -m pytest e2e ...` writes to the shared Supabase project.** Run only what a step names.
- Problems the e2e tests find in the app are reported, not fixed, in this plan.
- The offline suite stays network-free, and `python -m pyright backend/` (from the repo root) stays at today's 3 errors and 1 warning, all in `run_dev_server.py` and `filter_validation.py`.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Someone runs plain `pytest` in `backend/`: it must never collect `e2e/`, which writes to the shared database. → Task 2, `test_plain_pytest_never_collects_the_end_to_end_suite`.
2. `E2E_ENV_FILE` names a file that does not exist: the session must stop, not fall back to `backend/.env` and the shared database. → Task 2, `test_a_missing_e2e_env_file_stops_instead_of_using_the_shared_database`.
3. `SUPABASE_KEY` is the publishable key, or `SUPABASE_URL` is the dashboard page: S1 must stop with the fix, not let P1 fail later with a 500. → Task 2, `test_credentials_that_cannot_run_the_suite_say_why`.
4. Node.js is missing or `npm install` was never run: the dashboard checks must fail with the command that fixes it, not a stack trace. → Task 4, `test_a_frontend_without_npm_install_fails_with_the_fix`.
5. A run ends `completed_with_errors`: P2's failure message must name each stage with its status and error text. → Task 5, `test_a_failed_run_is_described_by_stage_with_its_error`.

"""
Settings and safety checks for the end-to-end suite.

Kept apart from conftest.py so the offline suite can test them: they are
what stands between a typo and writing to the wrong database.
"""
from __future__ import annotations

import os
from pathlib import Path
from typing import Optional

from dotenv import load_dotenv

BACKEND = Path(__file__).resolve().parents[1]
RESULTS_ROOT = BACKEND / "e2e" / "results"
TOPIC_CATALOG = BACKEND / "agents" / "topic" / "topic_catalog.json"

RUN_TIMEOUT = 300          # seconds: one pipeline run over stored articles
COLLECTION_TIMEOUT = 600   # seconds: one real collection run (fetches and downloads pages)
SERVER_TIMEOUT = 60        # seconds: starting the servers and building the frontend
PAGE_TIMEOUT = 30_000      # milliseconds: a page load or a dashboard update


def load_e2e_env(env_file: Optional[str] = None) -> Path:
    """
    Load the suite's credentials, overriding anything already set.

    E2E_ENV_FILE names the file (the future test database); without it,
    backend/.env. A named file that does not exist is an error: silently
    falling back to backend/.env would write to the shared database while
    you think you are testing somewhere else.
    """
    named = env_file if env_file is not None else os.environ.get("E2E_ENV_FILE")
    path = Path(named) if named else BACKEND / ".env"
    if named and not path.is_file():
        raise FileNotFoundError(f"E2E_ENV_FILE points at {path}, which does not exist.")
    load_dotenv(path, override=True)
    return path


def credential_problem(url: Optional[str], key: Optional[str]) -> Optional[str]:
    """Why these Supabase credentials cannot run the suite, or None if they can."""
    if not url or not key:
        return "SUPABASE_URL and SUPABASE_KEY are not set (backend/.env, or the file E2E_ENV_FILE names)."
    if key.startswith("sb_publishable_"):
        return ("SUPABASE_KEY is the publishable key, which cannot record pipeline runs. "
                "Use the secret key (sb_secret_...).")
    if "supabase.com/dashboard" in url:
        return "SUPABASE_URL is the dashboard page; use the API endpoint (https://<ref>.supabase.co)."
    return None
```

"""
End-to-end checks of the integrated pipeline, the API and the dashboard.

Run from backend/ (plain `pytest` never collects this folder):

    python -m pytest e2e              the real pipeline over 5 stored articles
    python -m pytest e2e --collect    plus one real RSS + GNews collection run

This writes to the Supabase project in backend/.env, or in the file that
E2E_ENV_FILE names. Design: docs/superpowers/specs/2026-10-08-e2e-testing-design.md
"""
from __future__ import annotations

import json
import os
from dataclasses import dataclass
from typing import Any, NoReturn
from urllib.parse import urlparse

import pytest

from e2e.settings import TOPIC_CATALOG, credential_problem, load_e2e_env


def pytest_addoption(parser):
    parser.addoption("--collect", action="store_true",
                     help="also run one real collection from RSS and GNews (never NewsAPI)")


def pytest_configure(config):
    # Before anything imports the app or an agent: their own load_dotenv
    # calls never override, so the values loaded here win.
    try:
        load_e2e_env()
    except FileNotFoundError as exc:
        raise pytest.UsageError(str(exc)) from None


@dataclass
class Environment:
    client: Any        # supabase Client
    registry: Any      # the AgentRegistry the test server's runs use
    database: str      # host only, never the key
    classifier: str
    topic_model: str


def stop(reason: str) -> NoReturn:
    """A setup check failed: nothing after it can work, so end the session."""
    pytest.exit(reason, returncode=2)


@pytest.fixture(scope="session", autouse=True)
def environment() -> Environment:
    """S1-S3: stops the session, with the reason, if the pipeline cannot run here."""
    url, key = os.environ.get("SUPABASE_URL"), os.environ.get("SUPABASE_KEY")
    problem = credential_problem(url, key)
    if problem or url is None or key is None:
        stop(f"S1: {problem}")
    from supabase import create_client

    host = urlparse(url).hostname or url
    client = create_client(url, key)
    try:
        client.table("pipeline_runs").select("id").limit(1).execute()
    except Exception as exc:
        stop(f"S1: cannot read pipeline_runs on {host}: {exc}")

    from agents.adapters import TopicAgent
    from orchestrator import build_default_registry
    from orchestrator.registry import TOPIC_MODELS
    from orchestrator.stages import CLASSIFICATION, TOPIC

    registry = build_default_registry(live=True, backlog=True, backlog_limit=5)
    if not isinstance(registry.get(TOPIC), TopicAgent):
        stop("S2: the topic stage would be a stub here: its model is missing or only a Git LFS "
             "pointer. Run `git lfs pull` and `pip install -r requirements.txt`.")
    classifier = ("LLM (Luna), keyword scorer as fallback"
                  if registry.get_fallback(CLASSIFICATION) is not None
                  else "keyword scorer (no LLM keys set)")
    models = json.loads(TOPIC_CATALOG.read_text())["models"]
    topic_model = ", ".join(f"{name} ({reg['version']})" for name, reg in models.items()
                            if (TOPIC_MODELS / name).is_file())
    return Environment(client, registry, host, classifier, topic_model)
```

```python
"""
The session's results file: one row per check, the database footprint,
and the failures with their screenshots.

Pure functions, so the offline suite can test the formatting; conftest.py
feeds them from pytest's reports.
"""
from __future__ import annotations

from collections import Counter
from dataclasses import dataclass, field
from typing import Dict, List, Optional


@dataclass
class Check:
    name: str
    outcome: str = "passed"      # passed, failed, skipped or error
    seconds: float = 0.0
    notes: List[str] = field(default_factory=list)
    screenshots: List[str] = field(default_factory=list)
    error: str = ""


@dataclass
class Footprint:
    before: Dict[str, int]       # row count per table
    after: Dict[str, int]
    rewritten_classifications: int
    run_ids: List[int]
    article_ids: List[int]


def duration(seconds: float) -> str:
    if seconds < 60:
        return f"{seconds:.1f}s"
    minutes, rest = divmod(round(seconds), 60)
    return f"{minutes}m {rest}s"


def cell(text: str) -> str:
    """Text that is safe inside a Markdown table cell."""
    return text.replace("|", "\\|").replace("\n", " ")


def change(before: int, after: int) -> str:
    delta = after - before
    return f"{delta:+d}" if delta else "0"


def render(header: Dict[str, str], checks: List[Check], footprint: Optional[Footprint],
           stopped: Optional[str] = None) -> str:
    counts = Counter(c.outcome for c in checks)
    failed = counts["failed"] + counts["error"]
    lines = [f"# End-to-end results, {header.get('Date', '')}", "", "| | |", "|---|---|"]
    lines += [f"| {key} | {cell(value)} |" for key, value in header.items() if key != "Date"]
    lines += ["", f"**{counts['passed']} passed, {failed} failed, {counts['skipped']} skipped** "
                  f"in {duration(sum(c.seconds for c in checks))}"]
    if stopped:
        lines += ["", "## Stopped early", "", stopped]

    lines += ["", "## Checks", "", "| Check | Result | Time | Notes |", "|---|---|---|---|"]
    lines += [f"| {c.name} | {c.outcome} | {duration(c.seconds)} | {cell('; '.join(c.notes))} |"
              for c in checks]

    if footprint is not None:

"""
Direct Supabase queries: the suite's independent view of the database.

Expected values come from here, never from the code under test. Any query
that can return more than PostgREST's 1,000-row page reads in pages.
"""
from __future__ import annotations

from typing import Any, Callable, Dict, List, Tuple

# The tables a run writes to, for the before/after footprint.
FOOTPRINT_TABLES = ("pipeline_runs", "pipeline_stage_runs", "articles",
                    "classification_results", "topic_results")


def page_all(make_query: Callable[[], Any], size: int = 1000) -> List[Dict[str, Any]]:
    rows: List[Dict[str, Any]] = []
    while True:
        page = make_query().range(len(rows), len(rows) + size - 1).execute().data
        if not page:
            return rows
        rows.extend(page)


def max_id(client: Any, table: str) -> int:
    rows = client.table(table).select("id").order("id", desc=True).limit(1).execute().data
    return rows[0]["id"] if rows else 0


def row_count(client: Any, table: str) -> int:
    return client.table(table).select("id", count="exact").limit(1).execute().count or 0


def snapshot(client: Any) -> Dict[str, Tuple[int, int]]:
    """(row count, highest id) for each table a run writes to."""
    return {table: (row_count(client, table), max_id(client, table)) for table in FOOTPRINT_TABLES}


def ids_above(client: Any, table: str, after_id: int) -> List[int]:
    rows = page_all(lambda: client.table(table).select("id").gt("id", after_id).order("id"))
    return [row["id"] for row in rows]


def count_since(client: Any, table: str, column: str, since_iso: str) -> int:
    return client.table(table).select("id", count="exact").gte(column, since_iso).limit(1).execute().count or 0

"""
The backend and the built frontend, served from threads for one session.

Both bind to free ports on 127.0.0.1, so they never collide with dev
servers on 5000 or 5173, and both stop when the session ends.
"""
from __future__ import annotations

import os
import shutil
import subprocess
import threading
from functools import partial
from http.server import SimpleHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path
from typing import Any

from werkzeug.serving import make_server

FRONTEND = Path(__file__).resolve().parents[2] / "frontend"


class FrontendBuildError(RuntimeError):
    """The frontend could not be built; the message says how to fix it."""


class ServerThread:
    """A server running on a background thread, used as a context manager."""

    def __init__(self, server: Any) -> None:
        self.server = server
        self.thread = threading.Thread(target=server.serve_forever, daemon=True)

    @property
    def url(self) -> str:
        host, port = self.server.server_address[:2]
        return f"http://{host}:{port}"

    def __enter__(self) -> "ServerThread":
        self.thread.start()
        return self

    def __exit__(self, *exc_info: Any) -> None:
        self.server.shutdown()
        self.server.server_close()
        self.thread.join(timeout=10)


class _QuietHandler(SimpleHTTPRequestHandler):
    def log_message(self, format: str, *args: Any) -> None:   # keeps pytest's output readable
        pass


def serve_backend(app: Any) -> ServerThread:
    return ServerThread(make_server("127.0.0.1", 0, app, threaded=True))


def serve_static(directory: Path) -> ServerThread:
    return ServerThread(ThreadingHTTPServer(("127.0.0.1", 0), partial(_QuietHandler, directory=str(directory))))


def build_frontend(out_dir: Path, api_base_url: str, frontend_dir: Path = FRONTEND, timeout: int = 60) -> None:
    """The production build, pointed at `api_base_url`, written to `out_dir`."""
    node = shutil.which("node")
    if node is None:
        raise FrontendBuildError("Node.js is not installed or not on PATH: install it from "
                                 "https://nodejs.org, then run `npm install` in frontend/.")
    vite = frontend_dir / "node_modules" / "vite" / "bin" / "vite.js"
    if not vite.is_file():
        raise FrontendBuildError(f"Vite is not installed in {frontend_dir}: run `npm install` there first.")
    env = {**os.environ, "VITE_API_BASE_URL": api_base_url}
    try:
        result = subprocess.run(
            [node, str(vite), "build", "--outDir", str(out_dir), "--emptyOutDir"],
            cwd=frontend_dir, env=env, capture_output=True, text=True,
            encoding="utf-8", errors="replace", timeout=timeout,
        )
    except subprocess.TimeoutExpired:
        raise FrontendBuildError(f"The frontend build took longer than {timeout}s.") from None
    if result.returncode != 0:
        raise FrontendBuildError("The frontend build failed:\n" + (result.stdout + result.stderr)[-3000:])
```

def describe_run(run: Optional[dict]) -> str:
    """The run and every stage with its status and error text: what a failed run check prints."""
    if not run:

    lines = [f"run #{run.get('id')} is {run.get('status')}: {run.get('notes') or ''}".rstrip(": ")]

        detail = f" ({stage['error_detail']})" if stage.get("error_detail") else ""

```python
def topic_facet(client: Any) -> Dict[str, Any]:
    """The /results topic facet as Supabase's own exact counts give it."""
    topics = json.loads(TOPIC_CATALOG.read_text())["topics"]

    def exact(query: Any) -> int:
        return query.limit(1).execute().count or 0

    counts = {topic_id: exact(client.table("topic_results").select("id", count="exact")
                              .eq("stable_topic_id", topic_id))
              for topic_id in topics}
    items = sorted(({"label": topics[t]["label"], "count": n} for t, n in counts.items() if n),
                   key=lambda item: (-item["count"], item["label"]))
    unassigned = exact(client.table("topic_results").select("id", count="exact").is_("stable_topic_id", "null"))
    return {"counted": sum(counts.values()), "unassigned": unassigned, "items": items}
```

"""Small helpers for the dashboard checks."""
from __future__ import annotations

from pathlib import Path
from typing import Any, List

# Every chart label whose box pokes outside its <svg>. SVG clips to its
# viewport, so these are cut off on screen.
CLIPPED_LABELS = """() => [...document.querySelectorAll("svg.recharts-surface")].flatMap((svg) => {
  const s = svg.getBoundingClientRect();
  return [...svg.querySelectorAll("text")]
    .filter((t) => {
      const r = t.getBoundingClientRect();
      return r.left < s.left || r.top < s.top || r.right > s.right || r.bottom > s.bottom;
    })
    .map((t) => t.textContent);
})"""


def watch_console(page: Any) -> List[str]:
    """Collects console errors and uncaught page errors for the rest of the test."""
    problems: List[str] = []
    page.on("console", lambda msg: problems.append(f"console {msg.type}: {msg.text}")
            if msg.type == "error" else None)
    page.on("pageerror", lambda exc: problems.append(f"page error: {exc}"))
    return problems


def screenshot(page: Any, results_dir: Path, name: str, record_property: Any) -> None:
    page.screenshot(path=str(results_dir / name), full_page=True)
    record_property("screenshot", name)
